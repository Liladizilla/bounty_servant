Operating strategy

Rules grounded in what the current system can measure

SAFETY FIRST
01 / VERIFYProve the reward terms

Read the issue and newest comments. An amount in text is evidence to inspect, not proof of funding.

02 / PRIORITIZEScore is a filter, not a forecast

Use recency, reward evidence and competition signals to shortlist. Inspect the repository before committing time.

03 / TRACKCount outcomes, not promises

Keep investigation, submitted PR, acceptance and confirmed payment separate. No payout rate until outcome history exists.
